Módulo 01 • Conjuntos Nível Iniciante

Pertinência (∈) vs. Continência (⊆)

Dado o conjunto A = { 1, 2, {3}, 4 }, classifique como V ou F: I) {3} ∈ A; II) {3} ⊆ A; III) ∅ ⊆ A.

Dica: {3} aparece como elemento direto dentro de A. Para usar ⊆, seria preciso {{3}} ⊆ A. O vazio ∅ é subconjunto de todo conjunto.
Resolução: I) V; II) F; III) V.
2.1
Módulo 02 • Base & Dimensão Nível Intermediário

Independência Linear (LI/LD) e Base de R²

Os vetores v₁ = (1, 2) e v₂ = (3, 5) são Linearmente Independentes (LI)? Formam base para R²?

Dica: Calcule det = (1·5) - (3·2). Se det ≠ 0, são LI e formam base de R².
Resolução: det = 5 - 6 = -1 ≠ 0. Logo são LI e formam base de R².
3.1
Módulo 03 • Transformações Lineares Nível Avançado

Núcleo e Isomorfismo

Seja T(x, y) = (x + y, x - y). T é um isomorfismo de R² em R²?

Dica: Verifique o determinante da matriz canônica [[1, 1], [1, -1]].
Resolução: det = -1 - 1 = -2 ≠ 0. Como ker(T) = {(0,0)}, T é bijetora e inversível: é um isomorfismo.
4.1
Módulo 04 • Teoria de Filas Nível Master

Simulação com Teoria de Filas (M/M/1)

Chegam λ = 10 alunos/h e o servidor atende μ = 12 alunos/h. Calcule ρ e L.

Dica: Use ρ = λ/μ e L = λ/(μ - λ).
Resolução: ρ = 10/12 ≈ 83,3% e L = 10 / (12 - 10) = 5 alunos.
